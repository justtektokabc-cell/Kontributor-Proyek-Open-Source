# Kontributor-Proyek-Open-Source
Tugas Besar Struktur Data IF-49-REG10: kontributor dan repository open-source dengan MLL-01 dan BST (C++)
## Deskripsi
Aplikasi console C++ untuk mengelola kontributor dan repository
open-source beserta peran dan jumlah commit tiap kontributor.
## Fitur
- Tambah, cari, dan hapus kontributor, repository, dan relasi
- Tambah star dan catat commit
- Tampilkan repository trending beserta maintainer
- Tolak penghapusan maintainer terakhir
- Fitur mendatang saat pengembangan (COMING SOON)
## Struktur Data
- MLL-01: list kontributor, list repository, relasi di dalam parent
- BST: peringkat repository dengan key jumlah star
 (key kembar masuk subtree kanan)
## Cara Menjalankan
1. Clone repo ini.
2. Buka file .cbp dengan Code::Blocks.
3. Build and run (F9).
